# Hello! 👋
I'm a 14 year old developer from Colombia who makes game mods (mainly Geometry Dash), tools, and other fun projects :)

I mainly work on making mods for [Geode SDK](https://geode-sdk.org) but every once in a while I'll work on some other stuff

My main programming languages are Python, C++ and Rust, and I also know a little bit of Reverse Engineering

You probably know me for some of my projects:
- [User Mentions (CommentMentions)](https://github.com/xblazegmd/CommentMentions) - Adds @mentioning to Geometry Dash
- [OMG!](https://github.com/xblazegmd/OMG) - Plays an iconic reaction whenever you beat a level
- [Server Errors](https://github.com/xblazegmd/server-errors) - Display server errors in a more detailed way
- [CBS Indicator](https://github.com/xblazegmd/cbs-indicator) - Adds a watermark for when you're using CBS/CBF
- [Are You Comment Banned?](https://github.com/xblazegmd/AreYouCommentBanned) - Quick script to see if you're comment banned
